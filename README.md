# 📝 React & Bootstrap Görev Yöneticisi (Todo App)

Modern web geliştirme konseptlerini uygulamak ve pekiştirmek amacıyla geliştirilmiş, kullanıcı dostu bir Görev Yöneticisi (Todo) uygulamasıdır. 

🚀 **Canlı Demo:** https://app.netlify.com/projects/esma-kaya-react-todo/overview

## 🎯 Projenin Amacı
Bu proje, modern JavaScript çerçeveleri kullanılarak temel CRUD (Create, Read, Update, Delete) operasyonlarının nasıl yönetileceğini göstermektedir. Göz yormayan, sade ve işlevsel bir arayüz hedeflenmiştir.

## ✨ Özellikler
- **Görev Ekleme:** Yeni görevleri listeye hızlıca dahil etme.
- **Görev Listeleme:** Eklenen tüm görevleri düzenli bir yapıda görüntüleme.
- **Görev Güncelleme:** Mevcut görevler üzerinde anında (inline) değişiklik yapabilme.
- **Görev Silme:** Tamamlanan veya istenmeyen görevleri listeden çıkarma.
- **Responsive Tasarım:** Her cihaza uyumlu esnek yapı.

## 🛠️ Kullanılan Teknolojiler
- **Frontend Framework:** React (Vite ile oluşturuldu)
- **Stil & UI:** Bootstrap 5
- **Durum Yönetimi:** React Hooks (`useState`)
- **Dağıtım (Deployment):** Netlify

## 📂 Kurulum ve Çalıştırma
Projeyi kendi bilgisayarınızda çalıştırmak isterseniz:

1. Projeyi klonlayın: `git clone https://github.com/EsmaKayaa/react-todo-app.git`
2. Klasöre gidin: `cd todo-app`
3. Gerekli paketleri yükleyin: `npm install`
4. Geliştirici sunucusunu başlatın: `npm run dev`
